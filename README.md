# 人生五年

比较中国“六五”至“十五五”规划的关键词、篇章顺序与措辞，介绍相关变化及其与日常生活的联系。本站为独立整理的阅读项目，非官方发布或授权解读。

项目采用原生 HTML、CSS、JavaScript。无需账号、后端、模型密钥或运行时外部接口；既能在浏览器本地打开，也能部署到 GitHub Pages。

## 可以做什么

- **变化趋势**：查看主题分析，对比85个关键词的次数或每万汉字次数，了解篇章顺序和层级。首页默认进入本节。
- **结论与行动**：48条生活参考，按7类工作形态/人生阶段与教育、就业、住房、健康、生活、养老6个领域交叉筛选。每条附规划内容、具体步骤和适用条件。
- **证据库**：提供逐期阅读、567条篇章标题、14个重点词的逐次命中及数据下载。逐期阅读可直接打开醒目标注的官方原文；原文片段也保留在具体分析的详情中。页面已移除方法与来源模块，研究口径和版本说明保留在仓库文档中。

“篇章顺序”提供20个议题，固定展示六五至十五五十期。可切换篇、章、编或顶层部分分别观察。各期匹配原标题全部保留，目录间断不跨期连线，首次匹配、未再匹配与再次匹配也会显示。“未匹配”仅表示在本版标题规则下没有命中，不能据此判定议题或政策消失。

图中圆点为原标题位置，折线与菱形为各期同层级匹配标题顺序的中位数。偶数个标题取中间两值的平均；半整数不对应实际篇章。只连接相邻、均有该层级数据的时期。中位数用于概括位置分布，目录拆分、总篇章数和匹配范围变化都会影响曲线。

人群导航使用在学/初入职场、办公室/专业岗位、现场/技能岗位、灵活/平台就业、个体/小微经营、待业/转岗、临近退休/退休。它不是互斥身份、社会等级或官方分类。六个生活领域为教育、就业、住房、健康、生活、养老；“生活”涵盖育儿、收支和公共服务等事项。尚未形成有充分依据条目的组合，暂时留空。

建议保留既有编辑顺序，页面不显示优先级标签和排序说明。具体选择可结合每条的适用条件、步骤和原文依据。

## 本地打开

直接打开 `docs/index.html`。筛选、图表、引文和按需加载的上下文均支持 `file://`，不调用模型。

或使用 Python 3.10+ 启动静态服务：

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory docs
```

浏览器访问 `http://127.0.0.1:4173`。

## 复算与检查

数据构建只依赖 Python 标准库：

```bash
python scripts/build.py
python scripts/check.py
```

构建读取已公开的清洗语料、标题定位和人工审阅内容，再计算词频、验证引文并生成 `docs/data/`。不会读取早期个人报告，也不会把工作目录的绝对路径写进公开数据。

需要浏览器交互测试时，安装 Node.js 22+ 和开发依赖：

```bash
npm install
npx playwright install chromium
npm run test:browser
```

已有受支持浏览器时，可以通过 `BROWSER_EXECUTABLE` 指定可执行文件。测试截图保存在忽略的 `test-results/` 中。

## 发布到 GitHub Pages

先运行 `python scripts/package_release.py`，将 `releases/` 中的公开源码压缩包解压到一个空文件夹，再上传该文件夹内容。压缩包只包含公开文件允许清单，不包含本地早期报告。

1. 将本项目允许公开的文件上传到你的 GitHub 仓库。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**。
3. 选择承载项目的分支及 **`/docs`** 文件夹，保存。

页面资源使用相对路径，支持仓库子路径。`docs/.nojekyll` 用于直接提供静态文件。操作依据见[GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。本项目没有绑定任何个人仓库地址或自动发布凭据。

根目录 `.gitignore` 使用公开文件允许清单：只有 `docs/`、`research/`、`scripts/`、`.github/` 和明确列出的项目文档进入候选文件。工作区中早期的报告、表格、网页快照、临时文件和本地依赖保留本地。发布前仍应查看 `git status`；忽略规则不会移除已经被跟踪的旧文件。

## 数据与证据约定

研究截止：**2026-10-19**。主语料覆盖1981—2030年的十期官方公开文件。

- `research/sources.json`：官方链接、原件哈希、语料哈希、版本和统计说明。
- `research/corpus/`：本版公开的清洗文本快照。
- `research/headings.json`、`research/locations.json`：原文标题、行号与页码定位。
- `research/order-topics.json`：20个议题的标题匹配规则，含纳入、排除条件与说明；`scripts/order_data.py` 据此生成十期状态和原标题配对。
- `scripts/*-source.json`、`scripts/development-actions.json`、`scripts/practical-actions.json`：审阅后的发现、行动和原文片段。
- `docs/data/`：自动生成的网页数据、词频CSV、篇章CSV及核验摘要。
- `docs/data/order-topics.csv`：议题与标题的配对明细；空缺状态保留在 `research.json` 的 `order_periods` 中。

每段结论引文都必须在所标章节中连续出现；不能用相似句、解读或《建议》替换正式《纲要》原文。位置按实际命中行追溯到PDF页码；HTML按网页定位。引文保留提取文字，不补写PDF文字层中缺失的标点。

**事实、推断与行动分别标识。** 原文中的政府任务，不直接等于个人已经取得的资格、收益或待遇。对投资、医疗、就业等问题，本项目提供阅读与核验框架，不从词频推导资产回报、临床效果或岗位保证。

## 已知局限

1. 六五、七五主统计使用官方公开摘要，不是完整书版。早期摘要与后期纲要不可无条件比较。
2. 计数从首个正文顶层部分开始，排除目录、序言/绪论、前置引言及网页页脚；图像文字未全部转写。
3. 八五、九五、十四五包含远景内容；篇幅、体例和任务范围不同。规范化词频不能消除这些差异。
4. 数字组词和议题可能迁移；同一字面词的含义也会变化。词频不是重视程度评分。
5. 十五五仍在实施；没有进行逐地待遇或完成情况核验，也没有形成全议题因果回测或预测胜率。
6. 公开语料可直接复算。本版未提供从全部原始扫描件重新OCR并自动校勘的端到端流水线，原始文件仍须通过来源链接核对。
