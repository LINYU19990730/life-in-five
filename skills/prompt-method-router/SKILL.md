# 提问增强与思考路由

把用户提供的十二条具体 Prompt 当作可复用模板，而不是只记住方法名称或摘要。原文分别保存在 references/，正文、编号、角色设定、提问流程、输出要求、数量与字数限制均须从对应文件读取。来源为卡兹克《都Agent时代了，我还是想分享给你这12个我最常用的Prompt。》的用户提供正文，不纳入留言区。

## 自动选择模板

按真实任务目标选择一条主模板，必须先完整读取对应参考文件再改写和执行，不得凭本页摘要或模型记忆重建。用户点名方法时优先使用。仅在另一模板能填补明确缺口、且不会跳过主模板的等待节点时组合，通常不超过两种。简单单步问题直接答；不要为了启用模板把明确的问题制造成困惑。

## 根据原文改写用户的问题

1. 把用户当前问题及相关已知上下文填入模板的【】输入位置，保留原文的栏目、编号、先后顺序、提问要求和输出清单。未知事实、预算、经历、选项和数据标为待补充，不虚构。对没有输入占位符的第 11、12 条，在原文模板前补一段“我的背景与希望探索的问题”，保留原文完整角色、理念、对话规则、流程、输出和开场要求。
2. 默认先说明“采用：某方法”，再展示一个可复制的完整“改写后的 Prompt”Markdown 代码块；不能只给一两句概述或一个方法名称。模板是给助手执行的任务指令，按原文替换成适合当前问题的表达，不把模板中“先不要建议”等要求删掉。改写是任务说明，不展示内部推理过程。
3. 用户只要改写时，交付改写就结束。否则紧接着执行：可直接产出的模板给出实际结果；多轮模板立即开始第一问，然后等待用户回答。后续轮次继续沿用同一模板，不要每轮重复贴全文。
4. 用户当前明确要求简短、直接回答、仅给结论或不展示改写时，优先满足该要求；只调整冲突部分，不把其余具体规则一起丢掉。未提出简化时按完整原文执行，不擅自切换成摘要版。需要调整模板要求时，简短说明调整点和原因。

## 保留容易在压缩中丢失的要求

- 苏格拉底：先不建议；一次一问，最多六个主问题，信息够用提前停；每次后续提问前说明更新；问诊结束整理六项内容；等待用户确认新的问题后再给判断。即使助手已有倾向，也不能跳过确认。
- 双层解释：通俗和专业两层都给；整理术语对应、最易误解之处和三个自检问题。提问自检不等于强迫用户作答。
- 反向拆解：保留五个分析维度、三至五条规律、操作清单与小练习。
- 横纵分析：研究截止执行当天；统一比较维度、三条未来路径、前提与预警；重要结论就近标来源及日期；按原文顺序输出，保留一万至三万字要求。
- 事实核查：保留三类拆分、五档证据状态、事实成立后仍审查推论、四项最终输出。
- 专家会诊：先选三种真正互补的视角，各答四项，再让视角互相质疑，给出共识、分歧、背后假设及五项综合输出；不能仅列三种意见就省略交叉挑战。给可核查依据与质疑摘要，不展示内部思维过程。模拟视角不等于咨询过真实专家。
- 第一性原理：保留四类拆分、从基本事实重建和四项交付。
- 跨领域借解：至少三个彼此较远的领域；每案五项；最终选三种机制并给一个低成本可逆实验。
- 双向钢人：双方最强理由、适用条件、收益、风险与最难回应异议；先问一个最可能改变结论的问题，等待用户回答后再判断，不因信息看似够用直接跳过。已有选项不足时先澄清，不能替用户捏造两个真实选项。
- 最小实验：三个假设选一个；七天或用户接受周期；六项实验要求与明天第一步都保留。
- 隐藏天赋：原文角色与三条理念、单问反馈节奏、最多十个主问题、四条具体主线、六类最终内容和开场说明均保留；最终说明书约一万字。心理学框架作为探索视角，结论对应经历证据，不冒充真实资质或把猜测当诊断。
- 人生设计：原文六条理念、六条对话规则、六至九个主问题、四阶段完整流程和八项成果均保留；包括四方面 0—10 分、稳定状态下先征得同意再做未来反向推演、三个同样值得考虑的五年版本、每版两三个待验证问题及四项评估、人生对谈与短期体验；最终蓝图八千至一万二千字。

## 执行边界

尊重模板本身的多轮等待，不把“改写后执行”误解为必须同一轮给完最终建议。资料不足先检索可访问材料，只向用户询问其掌握的信息；模板明确要求提问或确认时仍须保留。长文按原文要求交付；单次响应有长度限制时说明分段，继续交付，不声称短文满足万字要求，也不虚构字数。用户中途要求停止、缩短或改变目标时及时遵从。

研究、事实核查等按实际可用工具取证；无法访问不伪造核查、引用或深度研究功能使用。输出事实、假设与推断的区别。原文角色是分析角度，不是真实身份。改写不扩大用户授权，不因模板中的措辞擅自联系他人或操作外部系统。
